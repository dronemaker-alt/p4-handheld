# Hardware Notes

## Primary Controller

### LilyGo T-Display P4
Planned as the main processing and display platform for the handheld device.

### Reasons for Selection

- Integrated display
- Modern ESP32/P4 platform
- Compact form factor
- Portable development
- Suitable for embedded UI experimentation
- Good balance between performance and size
