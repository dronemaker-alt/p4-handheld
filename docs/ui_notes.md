# UI Notes

## Interface Philosophy

The UI direction combines:

- Aviation instrumentation
- Industrial handheld equipment
- Embedded diagnostics
- Science-fiction computer interfaces
- Minimal but information-dense layouts

---

## Core Goals

- Fast readability
- Simple navigation
- Physical button usability
- Portable field operation
- Low visual clutter
- Responsive menu system

---
