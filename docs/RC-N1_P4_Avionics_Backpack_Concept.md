# RC-N1 + LilyGo T-Display P4 Avionics Backpack Concept

## Objective
Create a removable mission-computer display for the DJI RC-N1 controller using the LilyGo T-Display P4.

## Current Findings
- P4 physically fits within the RC-N1 phone holder.
- Landscape orientation provides better access to ports.
- Side buttons, USB ports, Ethernet, antenna connectors, and SD card must remain accessible.
- The RC-N1 phone clamp can serve as the primary mounting structure.

## Mount Concept
- Four-corner capture design.
- Open sides for access to controls and connectors.
- Rear support plate.
- Slight display tilt for visibility.
- No permanent modification to the RC-N1.

## Future Functions
- Remote ID status display.
- MAVLink telemetry display.
- ELRS configuration and monitoring.
- ADS-B awareness tools.
- Flight logging.
- Mission planning.
- Protocol translation experiments.
